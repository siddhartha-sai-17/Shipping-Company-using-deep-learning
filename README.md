# Titanic_ANN

Titanic Survival Prediction using an Artificial Neural Network (ANN).

This repository contains a Streamlit application that loads a trained Keras
model to predict passenger survival on the Titanic dataset.

Files
- `app.py` — Streamlit app
- `requirements.txt` — Python dependencies
- `titanic_model.h5` — Trained model file
- `Titanic-Dataset.csv` — Dataset used for reference

Run
```powershell
pip install -r requirements.txt
python -m streamlit run app.py
```

Notes
- If the repository name differs from your local folder, that's expected —
	this project was pushed into the requested remote repository.
